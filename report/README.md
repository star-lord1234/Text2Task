# Text2Task final report

Two editions are built from the same sources:

- `Text2Task_Final_Report.pdf`: concise edition, 30 pages (`main.tex`, chapters in `concise/`).
- `Text2Task_Full_Report.pdf`: full edition, 94 pages (`main_full.tex`, chapters in `chapters/`).

Both share `preamble.tex` (styles) and `cover.tex` (themed TikZ cover). Everything needed to rebuild them is in this folder.

```
report/
├── main.tex                  concise edition (30 pages)
├── main_full.tex             full edition (94 pages)
├── preamble.tex, cover.tex   shared styles and cover
├── concise/                  chapters of the concise edition
├── references.bib            BibTeX bibliography (natbib, plainnat)
├── chapters/                 chapters of the full edition (00_abstract … 17_conclusion, A_appendices)
├── figures/
│   ├── architecture/         TikZ sources of all diagrams (included with \diagram{name})
│   ├── charts/               vector PDF charts generated by scripts/make_charts.py
│   └── screenshots/          application screenshots and verbatim terminal excerpts
├── data/                     stats.json (all numbers), live_example_analysis.json, schema copy
├── scripts/
│   ├── extract_stats.py      saved results  → data/stats.json
│   ├── make_charts.py        data/stats.json → figures/charts/*.pdf
│   ├── capture_screenshots.mjs  running app → figures/screenshots/*.png
│   ├── make_cover_motif.py   cube pattern on the cover → figures/cover_motif.tex
│   └── verify_numbers.py     checks 47 report numbers against data/stats.json
├── technical_verification.md evidence for every major claim; what was not re-verified
├── Text2Task_Final_Report.pdf
└── Text2Task_Full_Report.pdf
```

## Rebuild

Requirements: the project `.venv`, Python with `matplotlib` (only for charts), Node with the frontend's `node_modules` (only for screenshots), and a LaTeX engine. The report was built with [Tectonic](https://tectonic-typesetting.github.io) (XeTeX; downloads packages on first use); `latexmk -xelatex` with BibTeX also works.

```sh
# from the repository root
python report/scripts/extract_stats.py            # 1. collect numbers (standard library only)
python report/scripts/make_charts.py              # 2. charts (pip install matplotlib)
python report/scripts/verify_numbers.py           # 3. 47/47 checks should pass

# 4. optional: screenshots from a running app with the real models, on a scratch database
T2T_DB=/tmp/report.db .venv/bin/python -m uvicorn src.api.main:app --port 8799 &
node report/scripts/capture_screenshots.mjs http://127.0.0.1:8799

cd report && tectonic main.tex && cp main.pdf Text2Task_Final_Report.pdf
tectonic main_full.tex && cp main_full.pdf Text2Task_Full_Report.pdf
```
